# Amarktai Sales Assistant

**Amarktai Sales Assistant** is a responsive, visual product landing page and two-factor authentication interface for a modern automated sales assistant. The site presents the product as part of the **Amarktai Network** and follows the in-project **Signal Garden** visual system.

## Included pages

| Route | Purpose |
| --- | --- |
| `/` | A colorful marketing landing page with product story, workflow, security, and CTA sections. |
| `/auth` | A polished six-digit two-factor sign-in interface. It is a frontend presentation screen; production verification requires an identity provider or authentication backend. |

## Local development

Install project dependencies and run the development server with:

```bash
pnpm install
pnpm dev
```

Run a production build with:

```bash
pnpm build
```
